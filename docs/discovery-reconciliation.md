- Stable IDs are unique within each source, runtime, and searchable surface.
- Every runtime category has a category definition.
- Every runtime record has one deterministic canonical route.
- Planned records are retained in the inventory but have no guide route and are not represented as currently usable.
- Search exclusions, source-only IDs, runtime extensions, empty categories, and category definition drift remain visible.
- Functional verification, crawl outcomes, search ranking, AI citation, store publication, and platform parity require separate evidence ledgers and are not inferred from this report.
