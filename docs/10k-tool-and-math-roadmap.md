# enV 10,000-tool roadmap

## Current checkpoint

The catalog is intentionally growing through executable tools rather than placeholder rows. This checkpoint expands the calculator ecosystem with formula-driven STEM and exercise calculators.

## Quality rules

1. A tool counts toward 10,000 only when it represents a distinct useful task and has executable behavior.
2. Formula tools must expose the relevant formula and validate numeric inputs.
3. Exercise-oriented calculators should support solving for meaningful unknowns rather than only repeating a single answer.
4. Unsupported API/model/server capabilities stay Coming Soon.
5. Every expansion runs the catalog audit and regression checks.
6. Prefer reusable engines and data-driven definitions so thousands of tools do not require thousands of duplicated UI components.

## Expansion lanes

- Mathematics: arithmetic, algebra, geometry, trigonometry, coordinate geometry, sequences, calculus, statistics, probability, discrete mathematics, number theory, financial mathematics.
- STEM: physics, chemistry, electrical engineering, mechanics, thermodynamics, waves, optics, astronomy and engineering formulas.
- Practical calculations: construction, business, ecommerce, productivity, education, travel, cooking and everyday planning.
- Converters/reference tools: expand only when each conversion is useful and correctly implemented.
- Media and creator tools: continue only when the underlying browser/native/server capability exists.

## Parallel development

One agent can audit distant catalog categories backward while another expands forward-facing product infrastructure. Changes must be merged through full-project checkpoints and catalog audits.

## September 2026 systematic math expansion v3

The math calculator layer now includes executable exercise families for calculus, introductory statistics, and financial mathematics. These are generated as solve-for-unknown tools and are backed by the shared calculator engine rather than placeholders.

New families include power-rule derivatives, common trigonometric/log derivatives, antiderivatives, definite linear integrals, trapezoidal approximation, function average value, annuities, present value, APY, sample variance, covariance, standard scores, and confidence-interval margin of error.
