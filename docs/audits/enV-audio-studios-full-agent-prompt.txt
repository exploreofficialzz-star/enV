# Mission

1. Restructure Audio into **Audio Studios** (like Accessibility / Business).
2. **Configure every existing tool** so it actually works (or shows an honest
   configured/disabled state — never a blank broken shell).
3. **Add** Music Separator, Music Duet, and a curated set of high-value tools.
4. Collapse ~30 thin platform helpers into one Platform Guide Studio.
5. Ship local-first DSP; label server paths clearly; never market illegal
   Spotify/Apple Music downloaders.

--------------------------------------------------------------------------------
# HARD RULES
--------------------------------------------------------------------------------

1. No removal of existing `/tools/audio/*` URLs — map each to a Studio mode.
2. User audio files: prefer **in-browser** processing. If upload required
   (FFmpeg/STT), show explicit banner: “File is uploaded to the configured
   media endpoint for processing.”
3. **Do not build** Spotify / Apple Music / Amazon / Tidal DRM downloaders.
4. YouTube extract: only if media service already exists; require disclaimer.
5. Music Separator primary path = **browser model** (ONNX/WebGPU) when feasible;
   optional server fallback clearly labeled.
6. All new tools named with **audio-** or **music-** prefix for consistency.
7. Desktop + mobile usable; file inputs and primary buttons touch-friendly.
8. Web TypeScript primary; mirror calculators / simple DSP contracts on
   Android Kotlin + iOS Swift where practical (full stem AI may be Web-first).
9. Empty / unconfigured services must show **setup guidance**, not dead UI.

# PART 3 — NEW TOOLS TO ADD (ALL MUST WORK)
--------------------------------------------------------------------------------

### Music Studio (flagship)

#### music-separator
- Input: local audio file (user-owned)
- Output stems:
  - **2-stem:** Vocals · Instrumental  
  - **4-stem (optional):** Vocals · Drums · Bass · Other  
- Engine priority:
  1. Browser ONNX Runtime Web / WebGPU (UVR-MDX or Demucs-class port)
  2. Optional server GPU job if configured  
- First model download ~30–70 MB; cache in browser  
- Progress UI; max duration limit documented (e.g. 8–10 min on WASM)  
- Download each stem WAV; privacy strip: “Separation runs on this device when using browser model”

#### music-duet
- Depends on separator (or accept pre-split instrumental)
- Features:
  - Play instrumental
  - Record mic (getUserMedia)
  - Mix user vocal over instrumental (GainNodes)
  - Optional: mute original vocal stem
  - Optional pitch ±12 semitones, tempo 0.75×–1.25× (best-effort Web Audio)
  - Export mix WAV/MP3
- Use cases: karaoke, practice, duet, vocal replace for **files the user has rights to**

#### music-karaoke
- Shortcut mode: separator → instrumental only → optional lyric paste (display only, no claim of auto-sync accuracy unless implemented)
