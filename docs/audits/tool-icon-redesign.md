# enV Tool App-Icon Redesign Audit

Date: 2026-10-18

## Scope

The redesign gives every tool in the shared catalog a semantic Lucide glyph and a stable, individual app-icon tile treatment. The generated native catalog currently includes **10,025 tools across 43 categories** (including the additive audio-studio entries).

## Design system

- **91 semantic tool glyph families** map the tool's name, slug, keywords, category, description, and engine metadata to a meaningful icon rather than a category-wide generic calculator glyph.
- **Stable per-tool color identity** is based on FNV-1a hashes of the tool ID and a separate accent key. The Web catalog stores the resulting colors; Android and iOS compute the same colors from the tool ID. Each tile uses a rounded gradient, a subtle highlight, a decorative accent and a small glint.
- **9,977 distinct background/accent pairs** exist across 10,025 tools (99.52% distinct pairs). Tools preserve their icon and colors when opened on another platform or revisited later.
- **119 required shared glyph assets** are present for native Web parity, category navigation and shared interface controls.

## Integration coverage

- **Web:** shared `ToolAppIcon` is used in tool cards, Home shortcuts, tool detail headers and related tools.
- **Android:** native Compose `EnVToolAppIcon` is used in Home shortcuts, discovery cards, tool cards, detail headers, related tools, search suggestions and assistant recommendations.
- **iOS:** native SwiftUI `EnVToolAppIcon` is used in Home shortcuts, tool cards, detail headers, related tools, search suggestions and assistant recommendations.
- The native catalog is regenerated by `scripts/export-native-catalog.mjs`; shared PNG icon assets are bundled from `apps/shared/native-icons/icons`.
