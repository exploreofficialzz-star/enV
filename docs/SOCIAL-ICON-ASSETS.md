# Social icon assets

enV uses the exact upstream SVG logo paths from these projects, not hand-drawn substitutes.

- X, Instagram, TikTok, YouTube, Facebook, WhatsApp, and Snapchat: [Simple Icons SVG assets](https://github.com/simple-icons/simple-icons/tree/develop/icons). Simple Icons are released under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE).
- LinkedIn: [Bootstrap Icons LinkedIn SVG](https://github.com/twbs/icons/blob/main/icons/linkedin.svg), under the MIT license. The upstream license text follows.

The original SVG files are stored in `public/social-icons/` and in the iOS asset catalog. Android resources preserve the upstream SVG path data in VectorDrawable form. Platform UI displays the marks in a monochrome row with accessible link labels.

Brand names and logos remain the property of their respective owners; the assets identify the official profiles linked by enV and chAs Technologies LLC.
